# Touch Buttons

See-through on-screen buttons for touch screens. Bottom number row, L/R on the
right, shortcuts top left, and a touch/slide cursor toggle.

- Bottom row: tap 1-0 to pick a toolbar slot, icons included
- Right side: L uses the tool where you point, R does the action
- Top left: bag, map, menu/close
- T/S button: direct taps, or a slide cursor you drag like a touchpad

All buttons are ghosts by default so the game shows through. Opacity and every
cluster can be changed in Generic Mod Config Menu. Console command
`touchbuttons` turns the whole thing on or off.

Keep Cinderbox's own joystick for walking. This mod covers the buttons it
does not have.
